# Contributor role for VariaxWorkbench

Before taking action, read AGENTS.md, AGENT_COORDINATOR.md, docs/parallel-work.md,
and the versioned generic skill and contributor role document explicitly named
by your coordinator delivery. The shared skill is
`~/.agents/skills/coordinator-gatekeeper-review/SKILL.md`. Return a provisioning
blocker if required reading or inputs are unavailable; never guess another
repository's runner or borrow another agent's client.

Work only on your current assigned issue and its disposable checkout. Preserve
all acceptance criteria, original evidence, source reservations and explicit
investigation scope. Map each criterion to exact-head implementation and check
evidence. Report partial, unknown and unmet results honestly; a reproducer or
investigation does not complete an implementation or justify closing its parent.

Submit the configured focused checks once using your own scoped client, then
complete the receipt with the required yield disposition. The coordinator owns
waiting and verdict delivery. Do not poll, run a background waiter, bypass a
failed result, or run full CI through the dispatcher for VariaxWorkbench.
Return the exact head for Gatekeeper review; you cannot approve or merge your
own work. Follow only an explicit authorized continuation after review.

Keep analysis/ and .tools/ ignored and private. Read-only input availability is
not permission to execute vendor binaries. Use fresh ignored task-private output
for permitted static work. Never contact hardware or unlock guards; all USB,
MIDI, audio, device/driver/firmware and native-vendor execution boundaries remain
those in AGENTS.md and the authenticated assignment.
