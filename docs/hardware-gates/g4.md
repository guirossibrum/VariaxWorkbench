## Before approval

Use the Variax 600 through the PODxt Live on Linux, with stock
`snd-usb-pod` and the already-active processed or clean instrument
Record Send 1–2. Record the build, kernel and libasound versions. The
[#145/#146 contract] declares **78125/2 Hz** (39,062.5 Hz),
`RW_INTERLEAVED`, two signed packed `S24_3LE` channels and six bytes per
frame. The following three prerequisites remain unproven.

1. **PCM request.** Identify the exact ALSA setup request and verify that
   the current parameters on the prepared handle return `78125/2` from
   the rational getter. The integer bounds 39062 and 39063 do not identify
   a working request. Require whole frames, equal periods of 64–8192 bytes,
   1–1024 periods and a buffer of at most 60,000 bytes.
2. **Attachment binding.** Independently tie the same open capture handle
   to the current USB attachment (`0e41:4650`, interface 0, endpoint
   `0x82`, stock POD driver). Use that attachment’s raw ALSA card, device 0,
   subdevice 0. A card number, name or format alone is insufficient.
3. **Channel order.** Verify the Variax signal, already-active Record Send
   and physical left/right order on the chosen path.

Resolve these before the take. Any live prerequisite check needs its own direct
owner approval before opening a stream.

## Choose one path

- **DAW.** Record the DAW/server version, exposed input node/profile, hardware
  source clock, project/graph rate and conversion, if any. An integer-rate
  project needs verified conversion from the exact source clock. Confirm
  the path can run capture-only and close the hardware handle when stopped.
- **Workbench (#128).** Use one unlinked direct hardware capture PCM.
  Open acquires capture resources with the stream stopped. Setting hardware
  parameters and preparing acquires buffers and resets counters. Start
  submits isochronous input URBs. Drop clears PCM ownership and unlinks
  URBs when the stream has no other users. Close releases the acquisition
  and handle. Save exact-clock AIFF with its sidecar to new files. Reconcile
  #128's WAV criterion before approval because WAV requires an integer rate.

## Proposed limits and evidence

One attempt, up to **3 seconds of capture** and **30 seconds from open attempt
to release**. Confirm both bounds can be enforced before approval. Leave mixer,
monitoring, Record Send, routing and all device settings untouched. Use no
playback or re-amp. Stop at the limit or immediately on mismatch, disconnect,
overrun, suspension or other failure. Attempt cleanup on every exit. Record
stop reason, elapsed time, frames, negotiated parameters and channel map.
Record separate drop and close results or DAW/server evidence that hardware
capture ended and the handle was released. Treat uncertain release as failure
and end the run without reopening. Keep logs, audio and before/after settings
observations in ignored local storage.
